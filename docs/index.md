## 📺 サービスについて / About the Service

このシステムは以下の方針で運営されています:

- **景品表示法 / ステマ規制 遵守**: 全ての投稿動画に「広告」表示と `#PR` `#広告` ハッシュタグを必ず付与
- **人間によるレビュー**: 全ての投稿は運営者(ViFight)による事前承認を経て公開
- **著作権・商標保護**: 実在ブランド名・著名人の模倣を避けたコンテンツ生成
