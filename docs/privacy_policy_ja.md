## 2. 取得する情報

本サービスは、以下の情報を取得・利用します。

### 2.1 投稿に関する情報

- **TikTok アカウント情報**: TikTok Login Kit / Content Posting API を通じて、当事業が運営する TikTok アカウントの基本情報(ユーザー ID、表示名、プロフィール画像など)
- **投稿コンテンツ**: 当事業が生成・投稿する動画ファイル、キャプション、ハッシュタグ
- **投稿実績データ**: 投稿の再生数、いいね数、コメント数、シェア数(分析目的)

### 2.2 アフィリエイト連携情報

- **Amazon アソシエイト**: PA-API を通じて、商品情報(タイトル、価格、画像、レビュー数等の公開情報)
- **楽天アフィリエイト**: 楽天 API を通じて、商品情報(同上)
- これらは商品紹介および収益化目的でのみ使用します

### 2.3 サードパーティサービス利用情報

本サービスは以下の外部サービスを利用します:

- **Anthropic Claude API**: 動画企画・キャプション生成
- **Google Gemini API (Veo)**: 動画コンテンツ生成
- **Firebase (Google)**: データ保存・動画配信
- **Discord**: 内部承認プロセス(当事業者のみ使用)

## 3. 利用目的

取得した情報は以下の目的でのみ利用します:

1. TikTok 上での商品 PR 動画の投稿
2. アフィリエイト報酬の取得・管理
3. 投稿実績の分析および改善
4. 法令・利用規約の遵守

## 4. 第三者提供

当事業は、以下の場合を除き、取得した情報を第三者に提供しません:

- 法令に基づく場合
- 本サービスの運営に必要な範囲で、各 API 提供者(TikTok、Amazon、楽天、Google、Anthropic、Discord)へデータを送信する場合
- お客様の同意がある場合

## 5. クッキー・トラッキング

本サービスは現時点で公開ウェブサイトを運営しておらず、視聴者のクッキー情報を直接取得することはありません。
TikTok プラットフォーム上での視聴トラッキングは TikTok 自身のプライバシーポリシーに従います。

## 6. アフィリエイト広告の表示

本サービスが投稿するすべての動画には、景品表示法および TikTok コミュニティガイドラインに従い、以下のいずれかの方法で広告であることを明示します:

- 動画内に「広告」「PR」表示を焼き込み
- キャプション内に `#PR` `#広告` ハッシュタグを記載

## 7. データの保管期間

- 投稿関連データ: 当事業の事業継続期間中
- ローカル動画ファイル: 生成後 7 日間
- TikTok アクセストークン: 有効期限まで(自動更新)

## 8. データの安全管理

- API キー・認証情報は暗号化された設定ファイルで管理
- Firebase 認証情報はソースコードリポジトリに含めない
- 不正アクセス・改ざん・漏洩等を防止するため、適切な技術的・組織的措置を講じる
