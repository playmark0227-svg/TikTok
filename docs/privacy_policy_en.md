## 2. Information We Collect

### 2.1 Posting-related Information

- **TikTok Account Information**: Through TikTok Login Kit / Content Posting API, basic account information of the TikTok account operated by us (user ID, display name, profile image, etc.)

### 2.2 Affiliate Information

- **Amazon Associates**: Public product information (title, price, image, review count, etc.) via PA-API
- **Rakuten Affiliate**: Same as above via Rakuten API
- These are used only for product promotion and monetization purposes

### 2.3 Third-party Services

The Service uses the following external services:

- **Anthropic Claude API**: Video plan and caption generation

- **Firebase (Google)**: Data storage and video delivery
- **Discord**: Internal approval process (used by operator only)
